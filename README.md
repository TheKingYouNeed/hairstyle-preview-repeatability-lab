# Hairstyle Preview Repeatability Lab

An original, owner-disclosed field guide and interactive worksheet for
comparing virtual hairstyle references across controlled frames.

The resource helps readers distinguish stable visual signals from changes
caused by lighting, angle, texture, styling, and camera processing. It does not
predict haircut or color outcomes.

## Local preview

Serve this directory with any static HTTP server and open the root page.
